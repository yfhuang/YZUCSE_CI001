## Assignment Overview

### Assignment I: Build Your Own GitHub Repository

Learn to create and manage GitHub repositories, write documentation with Markdown, and publish a static site using GitHub Pages.

- Read the [assignment instructions](./AssignmentI/README.md) carefully.
- Create a GitHub account using your Gmail address.
- Create the course repository: `11501_CI001`.
- Create a personal website repository: `{username}.github.io`.
- Enable GitHub Pages and verify your site is accessible at `https://{username}.github.io/`.
- In the course repository, add a meaningful `README.md` including:
    - name
    - student ID
    - course
    - brief description
- In the personal website repository, add a descriptive `README.md` and a meaningful `index.html` with a brief self-introduction.
