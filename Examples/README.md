# Example Programs

These examples are intentionally short.

Recommended student workflow:

1. compile the file;
2. run it with your own input;
3. close it;
4. recreate the same program from a blank file;
5. modify one behavior.

Compile with GCC:

```bash
g++ -std=c++15 -Wall -Wextra -O2 file.cpp -o program
```

The examples are not intended to be submitted directly to UVa/CPE problems.
They are concept drills.
