# Self-Learning Roadmap

## Four learning levels

| Level | Focus | Evidence that you are ready to move on |
|---|---|---|
| Entry | C++ literacy | You can write short programs using input, output, conditions, and loops. |
| Developing | Basic problem solving | You can solve easy formula, classification, and digit-processing problems. |
| Medium | Reusable patterns + STL | You can use arrays/vectors, strings, sorting, search, map/set, matrices, and simulation. |
| Advanced / CPE-ready | Reliability under time | You can classify a problem, implement it, test edge cases, and solve two problems in a mock exam. |

## The three questions to ask every week

1. **Language:** What C++ feature do I need?
2. **Pattern:** What kind of problem is this?
3. **Judge:** What input/output detail can make an otherwise correct solution fail?

## Self-evaluation rule

Do not classify a topic as "learned" just because you understand the example.

Use these levels:

- **Level 0:** I do not understand the concept.
- **Level 1:** I understand when I read the solution.
- **Level 2:** I can reproduce the solution with hints.
- **Level 3:** I can solve a similar problem independently.
- **Level 4:** I can recognize and solve the pattern under time pressure.

For CPE preparation, aim for **Level 4** on the most common patterns.
