# Problem-Solving Patterns

At the entry level, students ask:

> Which C++ syntax should I use?

At the medium level, start asking:

> What kind of problem is this?

This folder builds a pattern library.

## Core recognition list

When you read a problem, ask whether it is mainly:

- formula substitution;
- classification;
- counting;
- accumulation;
- digit processing;
- min/max;
- frequency counting;
- sort then process;
- search;
- string scanning;
- matrix traversal;
- simulation;
- greedy choice;
- recurrence.

The fastest CPE solvers are not necessarily typing faster. They often recognize the pattern earlier.

## One-minute classification exercise

Before coding any practice problem:

1. write one sentence describing the required output;
2. identify the input structure;
3. name the likely pattern;
4. estimate the data size;
5. choose the smallest suitable data structure.

Do this before opening your old solution.
