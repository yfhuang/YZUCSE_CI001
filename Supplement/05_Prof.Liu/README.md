# Prof. Pang-Feng Liu Supplement Notes

This folder contains supplemental materials and study notes related to Prof. Pang-Feng Liu's C and C++ programming instruction. The materials support computer science students who are strengthening programming fundamentals, learning problem-solving patterns, and practicing UVa-style problems.

The contents provide connections between programming concepts and weekly on-site problem-solving topics. Students can use them to review core ideas, study guided examples, and develop clearer and more systematic coding habits.

## About Prof. Pang-Feng Liu

Prof. Pang-Feng Liu (劉邦鋒) is a professor in the [Department of Computer Science and Information Engineering](https://www.csie.ntu.edu.tw/) at National Taiwan University (NTU). His work includes parallel and distributed computing, algorithm design, and computer programming education. The materials in this folder use C and C++ examples to help students connect programming fundamentals with structured problem solving and on-site programming practice.

## Contents

- [C Programming with Idioms, 2nd Edition -> On-site Problem Mapping](C_Programming_with_Idioms_2nd_to_Onsite_Problems.md): Maps C programming topics, such as input/output, conditions, loops, arrays, and functions, to the weekly course themes and related on-site problems.
- [C++ Refactor -> On-site Problem Mapping](Cplusplus_Refactor_to_Onsite_Problems.md): Maps C++ concepts, such as strings, containers, structures, classes, and recursion, to the weekly course themes and related on-site problems.
