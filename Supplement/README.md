# Supplement Resources

This folder collects reusable study notes and AI prompt templates for UVa/CPE preparation. The supplements are organized in a more consistent learning flow: begin with C++ foundations and transition concepts, then move into problem-analysis habits, coding routines, and core algorithmic topics, ending with a real UVa case study.

## Supplements

- [Supplement_01_Learning_CPP_from_History.md](./Supplement_01_Learning_CPP_from_History.md) - Learn why C++ evolved the way it did, with curated historical context and video resources.
- [Supplement_02_Transition_Learning_CPP.md](./Supplement_02_Transition_Learning_CPP.md) - Connect high-school knowledge and basic math/logical thinking to C++ programming concepts.
- [Supplement_03_CPE_Examination_Preparation_Guide.md](./Supplement_03_CPE_Examination_Preparation_Guide.md) - Use short and long prompt templates to analyze CPE trends and prepare exam strategy.
- [Supplement_04_On_Site_Examination_Code_Evaluation_Prompt.md](./Supplement_04_On_Site_Examination_Code_Evaluation_Prompt.md) - Review on-site UVa/CPE-style code with structured AI evaluation prompts.
- [Supplement_05_Learning_Input_Patterns_via_UVa_Problems.md](./Supplement_05_Learning_Input_Patterns_via_UVa_Problems.md) - Practice recognizing common UVa input patterns and selecting robust input handling approaches.
- [Supplement_06_Preparing_Your_Codebook.md](./Supplement_06_Preparing_Your_Codebook.md) - Build and refine a personal C++ codebook for reusable templates and fast recall.
- [Supplement_07_Iteration_vs_Recursion.md](./Supplement_07_Iteration_vs_Recursion.md) - Compare iterative and recursive approaches, including trade-offs and suitable use cases.
- [Supplement_08_Data_Structures.md](./Supplement_08_Data_Structures.md) - Study data structures from fundamentals to advanced concepts with C++ examples.
- [Supplement_09_Learning_STL.md](./Supplement_09_Learning_STL.md) - Learn STL containers and algorithms, with practical examples for competitive programming.
- [Supplement_10_Learning_Algorithm.md](./Supplement_10_Learning_Algorithm.md) - Practice core algorithmic approaches such as dynamic programming, greedy, and divide and conquer.
- [Supplement_11_UVa_11063_B2-Sequence.md](./Supplement_11_UVa_11063_B2-Sequence.md) - Analyze UVa 11063 (B2-Sequence) with multiple solution strategies and data-structure trade-offs.

## Suggested Study Sequence

1. Start with Supplement 01 for language background and learning context.
2. Continue with Supplement 02 to bridge prior knowledge with programming concepts.
3. Read Supplement 03 to prepare for CPE-style analysis and exam strategy.
4. Use Supplement 04 to review your own code and identify weaknesses.
5. Practice with Supplement 05 to recognize input patterns quickly in UVa problems.
6. Build your reusable toolkit with Supplement 06.
7. Use Supplement 07 to choose implementation style between iteration and recursion.
8. Study Supplement 08 to strengthen data-structure foundations.
9. Read Supplement 09 to become fluent with STL containers and algorithms.
10. Study Supplement 10 to learn core algorithmic approaches.
11. Finish with Supplement 11 to apply multiple solution strategies to a real UVa problem.

## Suggested Workflow

- **Foundation stage:** Supplements 01 and 02.
- **Practice and coding habits:** Supplements 03, 04, 05, 06, and 07.
- **Core technical topics:** Supplements 08, 09, and 10.
- **Applied case study:** Supplement 11.
- **Exam stage:** Revisit Supplements 03 and 04 before mock tests or the actual CPE examination.
