# Supplement 01: Learning C++ from History (YouTube Collection)

This note collects selected videos to help students understand not only how to write C++, but also why the language evolved from C in a particular way.

## Why Learn the History?

Knowing the historical background helps you:

1. Understand why C++ emphasizes performance and control.
2. Interpret design choices such as RAII, templates, and zero-overhead abstractions.
3. Build better judgment when choosing between C-style techniques and modern C++.

## Suggested Learning Path

1. Watch Video 1 first to build a global view of how C++ evolved from C and Bell Labs research.
2. Watch Video 2 next to hear the original design philosophy from the language creator.
3. Watch Video 3 to reinforce and cross-check your understanding.
4. Watch Video 4 to connect C++ history with generic programming and the design of the Standard Template Library (STL).

## Reflection Questions for Students

After watching, try writing short answers to these questions:

1. What problems was C++ trying to solve that C alone could not solve conveniently?
2. What does zero-overhead abstraction mean, and why is it important in systems programming?
3. Which historical design decision still affects how we write C++ today?
4. Which modern C++ feature would you prioritize learning first, and why?
5. How do the STL's separation of algorithms and containers reflect generic-programming principles?

## Study Tip

Do not treat these videos as passive content. While watching, keep a timeline note (for example, C -> C with Classes -> C++ standardization -> modern C++) and connect each stage to concrete language features you have used in class. Record one example of a trade-off or design goal for each stage.
